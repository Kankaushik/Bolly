# bolly — Premium Organic Haircare

Welcome to **bolly**, a luxury organic shampoo brand landing page. 

This project is a beautifully designed, Scandinavian-inspired landing page built to showcase a premium cosmetic shampoo bottle. 

## Key Features

- **Interactive 3D Experience:** A photorealistic 3D cosmetic shampoo bottle floats on the page. Visitors can click and drag to rotate the bottle to inspect it from different angles.
- **Premium Aesthetics:** Features a modern, minimalist design with a soft lavender gradient, clean layouts, and elegant typography.
- **Custom WordPress Integration:** Built from scratch as a lightweight, custom WordPress theme and dedicated 3D showcase plugin.
